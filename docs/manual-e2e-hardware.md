# 実カメラによる手動E2E

合成フレームの自動E2Eとは別に、各OSのカメラ権限とMediaPipe実認識を確認します。顔画像、動画、音声、ランドマーク列を保存・添付しないでください。結果は成功／失敗、OS、カメラ種別、問題だけを記録します。

## 共通準備

1. `npm ci` と `npm run tauri dev` で開発ビルドを起動する。
2. ネットワーク切断時にも同梱モデルで起動できることを確認する。
3. OSのカメラ権限を初期化し、内蔵カメラとUSB Webカメラをそれぞれ用意する。
4. 明るい部屋と暗い部屋、眼鏡あり／なしを用意する。

## Windows

- 初回カメラ権限を許可し、拒否後の再試行ができる。
- 内蔵カメラ、USB Webカメラを一覧から切り替えられる。
- 顔を横へ向ける、まばたき、会話、口を開けたまま、顔へ一瞬触れる、頬杖、顔を数回こする動きを試す。
- カメラ付近を正面注視し、左右へ視線を動かす。必要なら再キャリブレーションする。
- 10分休止と復帰、アプリ終了時のカメラ解放、再起動後の設定・履歴保持を確認する。

## macOS

- システム設定のカメラ許可を許可／拒否して、拒否後の再試行を確認する。
- 内蔵カメラとUSB Webカメラ、眼鏡あり／なし、明暗条件を確認する。
- Windows項目と同じ動作に加え、別デスクトップへ移動したときも監視が継続することを確認する。
- 終了後にカメラの使用中インジケーターが消えることを確認する。

## 記録フォーマット

```text
日時: YYYY-MM-DD
OS / バージョン:
カメラ種別:
結果: 成功 / 失敗
問題:
```

診断名や医療上の結論を記録せず、再現に必要なUI状態と環境だけを記録してください。
