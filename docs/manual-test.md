# 手動テスト

## 初回起動

- [ ] 同意前にカメラが開始されない
- [ ] 同意後にOSのカメラ権限が表示される
- [ ] 権限拒否時に監視中表示にならない
- [ ] 再度開始して権限を許可すると映像が表示される
- [ ] モデル読み込み後は外部通信が発生しない

## 口の開き

- [ ] 一瞬口を開けても通知されない
- [ ] 設定時間を超えて開けると1回通知される
- [ ] 開け続けても通知が連打されない
- [ ] 閉じてクールダウン後に再検出できる
- [ ] 会話モード中は口だけ判定対象外になる

## 顔への手接触

- [ ] 手が顔から離れている状態で通知されない
- [ ] 一瞬触れただけでは既定設定で通知されにくい
- [ ] 頬を触り続けると通知される
- [ ] 顔の近くを往復させると擦過スコアが上がる
- [ ] 背景の別人や手に過度に反応しない

## 左右視線差

- [ ] 未校正では通知されない
- [ ] 横向きでは通知されない
- [ ] まばたき中は通知されない
- [ ] 正面注視でキャリブレーションを完了できる
- [ ] カメラ付近を見ると通常範囲になる
- [ ] 意図的に片目の視線だけをずらした状態で候補になる
- [ ] 医療診断を示す文言が表示されない

## ライフサイクル

- [ ] 10分休止でカメラのトラックが停止する
- [ ] 休止解除で同じカメラを再開する
- [ ] 監視停止でカメラ使用インジケーターが消える
- [ ] カメラ切替時に古いトラックが停止する
- [ ] 終了時にWorkerとカメラが解放される

## データ

- [ ] 履歴に画像が含まれない
- [ ] JSON書き出しに画像・特徴点列が含まれない
- [ ] 履歴削除後に再起動しても復元されない
- [ ] 本人基準削除後は左右視線差が要校正になる
