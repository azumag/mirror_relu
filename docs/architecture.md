# アーキテクチャ

## 1. 境界

Mirror Re:lu は、Tauriをデスクトップ配布とOS権限の境界にだけ使います。カメラ取得、推論、判定、履歴表示はWebView側で完結し、カメラフレームをRustへ送るIPCは設けません。

```text
┌──────────────────────── Tauri / Rust ────────────────────────┐
│ ウィンドウ、バンドル、OSのカメラ権限説明、CSP                 │
│ アプリ固有IPCコマンドなし                                     │
│  ┌──────────────────────── WebView ────────────────────────┐ │
│  │ getUserMedia → ImageBitmap → Vision Worker             │ │
│  │                              ↓                         │ │
│  │                    数値特徴量 VisionFrame              │ │
│  │                              ↓                         │ │
│  │ BehaviorEngine → TemporalGate → 通知 / localStorage    │ │
│  └────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

## 2. 推論パイプライン

1. `CameraController` が `getUserMedia` で1280×720、最大30fpsを要求します。
2. UIループが既定10fpsでフレームを採取します。
3. `createImageBitmap` で幅640pxへ縮小し、所有権をWorkerへ移します。
4. Face Landmarkerは毎回、Hand Landmarkerは既定2回に1回実行します。
5. Workerはプレーンな座標と表情係数だけを返し、`ImageBitmap.close()`を必ず実行します。
6. UIスレッドの`BehaviorEngine`が指標と時間状態を更新します。

フレームが滞留しないよう、Worker処理中は次のフレームを送信しません。

## 3. 指標

### 口の開き

```text
mouthOpenRatio = 上下の内唇距離 / 両目外側間距離
mouthScore = max(mouthOpenRatio, jawOpen × 0.32)
```

本人の閉口時中央値を基準とし、感度から加算幅を決めます。会話モード中は判定資格を失い、状態機械をリセットします。

### 顔への手接触

顔の額・顎・両頬から楕円を作り、各指の末節・指先について次の大きい方を採用します。

- 顔楕円の内部度
- 間引いた顔特徴点への最短距離

接触候補の軌跡を1.25秒保持し、移動距離と方向反転回数から「こする動き」の補助スコアを計算します。これは分類器ではなくヒューリスティックです。

### 左右視線差

左右の虹彩中心位置を、それぞれの目頭・目尻間で0〜1へ正規化します。キャリブレーション時の左右位置を引き、両眼の偏差差を求めます。

判定条件：

- 本人基準が存在する
- 顔が検出されている
- 正面度が0.72以上
- 両目の開きが0.13以上
- キャリブレーション中、休止中でない

この値は眼位角、プリズムディオプター、診断名を表しません。

## 4. 時間状態機械

```text
normal
  └─ enterThreshold以上 → candidate
candidate
  ├─ exitThreshold以下 → normal
  └─ holdMs継続 → active（1回通知）
active
  └─ exitThreshold以下がreleaseMs継続 → cooldown
cooldown
  └─ cooldownMs経過かつ正常値 → normal
```

進入閾値と解除閾値を分けるヒステリシスにより、境界付近の通知ちらつきを防ぎます。

## 5. キャリブレーション

45個の有効フレームを収集し、各指標の中央値を保存します。顔未検出、正面度不足、目を閉じている、顔へ手が触れているフレームは拒否します。古い本人基準を使わず、再校正中は生の虹彩差を収集します。

## 6. 保存データ

`localStorage`には以下だけを保存します。

- `mirror-relu:settings:v1`
- `mirror-relu:calibration:v1`
- `mirror-relu:events:v1`（最大200件）
- `mirror-relu:onboarding:v1`

スキーマ変更時は新しいキーへ移行し、旧キーを安全に読み捨てられるようにします。

## 7. 障害時の挙動

- GPU初期化失敗：CPUへ一度だけフォールバック
- カメラ拒否：監視を開始せず、権限案内を表示
- 顔未検出：全検出を対象外にして状態をリセット
- Workerエラー：処理中フラグを解除し、エラーを表示
- モデル欠損：監視開始を失敗させ、カメラを停止
